# 05 失分诊断库与提升路径（批改后的建议输出依据）

> 用法：批改完成后，将发现的失分点映射到本文件的"失分模式 → 根因 → 训练动作"，输出针对性建议；多次批改纵向对比，定位最薄弱环节，给出阶段路径。

## 一、失分模式 → 根因 → 训练动作 映射表

### A. 审题与方向类（最致命，偏题=整题崩盘）

| 失分模式 | 根因 | 训练动作 |
|---|---|---|
| 问做法答意义/问意义答做法 | 要素意识弱，分不清"做"与"夸" | 专项训练标志词区分："了着使让于能够"=意义；动词+名词在"做"=对策；每天 2 道只做审题判定不作答 |
| 漏看"一一对应/提纲/语言生动"等特殊要求 | 审题只审任务不审要求 | 强制审题三圈法：圈范围词、圈要素词、圈要求词，落笔前复述一遍 |
| 作文跑题/抽象句不解释 | 没审出题干类型 | 按四种出题方式（单一指向/抽象模糊/观点多/AB关系）分类刷题干，只写提纲不写全文，每次 10 分钟 |
| 误用话题无关的小题材料 | 读材料优先级错误 | 牢记顺序：指定资料→小题未用资料→话题一致的已用资料 |

### B. 要点类（权重最高，提分空间最大）

| 失分模式 | 根因 | 训练动作 |
|---|---|---|
| 整条遗漏（-5 分级） | 没按"1 段 1 条"梳理材料逻辑 | 复盘时先列材料段落角色表（背景/经验/举例/总结），再对答案；错题过几天重做 |
| 漏"等/省略号/还、同时、此外"后要点 | 并列信号不敏感 | 勾画时对这些符号做标记；复盘专项统计自己漏点位置规律 |
| 替换材料原词失分 | 改写冲动、追求"高级词" | 立规矩"可以加词不能改词"；做完对照材料数自己改了几个词 |
| 总括词自编跑偏/缺总括词 | 不知道 80% 总括词在材料中 | 专项练"找总括词"：例子后总结句、自问自答、高频词、"为了/得益于"后上位词 |
| 格子分配失控（首条过长/写不满一半） | 无草稿规划 | 打草稿只列关键词+定条数+按行均摊（12 行 3 条≈4 行/条） |
| 对策题丢实质名词 | 只抄动词 | 检查对策条中名词是否原词再现（窨井盖/养护技术知识类） |

### C. 结构类

| 失分模式 | 根因 | 训练动作 |
|---|---|---|
| 综合题缺释义/缺总结（丢逻辑分 2-3） | 三段式没形成肌肉记忆 | 每道综合题落笔前先写骨架"释义→展开→总结"三行 |
| 观点题表态与理由两张皮 | 表态后没自检呼应 | 写完反问：我的理由能推出我的表态吗？（"进步"必须有"过去不好+现在好"） |
| 公文背景写成主体/展开详写 | 背景角色不清 | 背景只写总结词 2-3 行；专项练"从材料提背景" |
| 提纲漏总起词 | 新规则不熟 | 记死：提纲每段"背景：/经验：/结语："各 1 分 |
| 作文缺"为什么"/五段三分裸奔 | 结构模板化 | 强制 6 段制：开头+过渡（关系/分析）+3 论证+结尾 |
| 评论类标序号 | 文体形式红线 | 记死：短评靠分段代替序号 |

### D. 语言与形式类

| 失分模式 | 根因 | 训练动作 |
|---|---|---|
| 文艺/比喻/啰嗦表达入答案 | 把申论当散文 | "但凡需要用句子就不应该是答案"；删修饰只留动宾/名词 |
| 作文观点句被文采掩盖 | 文采放错位置 | 观点句只留关键词，文采放论证段中间 |
| 落款真实日期/格式错误 | 格式规则不熟 | 格式自查表过一遍：标题/称谓/落款/日期（XXXX年XX月XX日右空4格） |
| 错别字、卷面涂改 | 书写习惯 | 用答题纸手写练习；作文 5 个错别字扣 1 分 |
| 字数硬伤（作文每少 50 字 -1） | 时间失控 | 小题 30 分钟/题限时训练；作文留足 60 分钟；写不满时启动作文"凑字"预案（排比例证扩充） |

## 二、分阶段提升路径（按当前水平给路线）

**阶段 0（摸底定位）**：限时做一套真题，按本 Skill 全维度批改，算出各题型得分率，对照目标（单一 80%/综合 60-70%/公文 75%/作文 60-80%）找到差距最大的模块。

**阶段 1（筑基：单一题 1-2 周）**："基础不牢地动山摇"。每天 2 道单一题，重点练：1 段 1 条梳理、总括词寻找、原词摘抄克制。达标线：得分率稳定 80%。

**阶段 2（综合+公文 2-3 周）**：综合题主攻三段结构完整性（先把逻辑分 3 分焊死）再抠要点；公文主攻格式三件套+背景处理+四类目的判定。格式分是"学了就能拿"的送分项，优先焊死。

**阶段 3（作文 2 周起，贯穿全程）**：先练"找观点"——只审题+列提纲（标题/中心论点/分论点句），对照定档标准自检，10 分钟/篇，量大于写全文；再练包装（标题四式、开头三公式、论证四句式、结尾三式）各选一式练熟。素材按五大领域（经济/治理/民生/文化/生态）积累，选短、通俗的背。

**阶段 4（套卷冲刺）**：180 分钟全真模拟，训练时间分配（小题 30 分钟、公文 35-40 分钟、作文 60 分钟）；复盘只看"哪个得分词漏了"，不纠结写多了。

## 三、复盘方法论（写给用户的训练建议话术）

- 复盘列思维导图：大逻辑（哪几段背景/经验/举例）+小逻辑（每条总结词与分述）——整理材料逻辑，读懂读透。
- 低于目标得分率的题：忘掉答案后过几天重做，重做仍低→该失分模式进个人专项清单。
- 首见新题型低分不必慌：合格线 60% 即可，课后片段作业分低不具参考性（片段题单词权重高）。
- 不要盲目对照参考答案自评：与答案相近未必是得分点，差异处反而可能有得分词；参考答案过于整洁是教研加工结果，朴素书写同样得分。

## 四、纵向诊断（多次批改时使用）

记录每次批改的：题型、得分率、失分模式标签（用本文件 A/B/C/D 编号）。连续 3 次以上出现同一标签→判定为"顽固性薄弱环节"，建议该模式对应的训练动作加倍，并在下次批改中优先检查该项是否改善。
