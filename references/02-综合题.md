# 02 综合题批改规则（词句解释题 + 观点现象分析题）

> 识别：问法模糊——"谈……的含义/理解/解释"（词句解释）或"见解/看法/评价/评析/认识"（观点现象）。
> 评分 = 逻辑分（2-3 分）+ 要点分（采点赋分）。目标：国考 60%、省考 70%（考场平均仅 30-40%）。

## 一、词句解释题："短—长—短"三段式

```
这句话是指：（短，约2分——就近原则）
具体体现在：1.……2.……3.……（长，采点主体，形式像单一题）
因此/未来/鉴于此……（短甚至无）
```

**第 1 段 总体释义（约 2 分）**：
- 就近原则：优先在画线句出处段找释义（出处段多在尾段或主体）；出处段没有则读全文概括（赋分较低）。
- 无现成释义时，从各展开部分总括词中"挑最大的词"拼出释义；释义要又短又采词，不写"XX做出了努力"类废话。

**第 2 段 展开解释（分数占比最高）**：
- 判断感情色彩：积极→找意义和对策；消极→找问题和危害。
- 看题干句表达方式定要素：句中有"要"→对策；"让/使"→意义；"只有……才……"→做法+意义；"是XX之源"→意义。**展开要素必须与题干句表达方式一致**。
- 句内含排比/并列（"穷帽子、老样子、好根子"）→ 按句子自带结构分类展开。
- 分条列点，以"具体体现在"引出；总括词不强制（不占分），写了更美观。

**第 3 段 总结对策**：材料有宏观总结句则摘抄；没有看剩余格子。**正面主题可不写，负面主题建议补充**（有问题就要给对策）。过渡词用"因此/未来/鉴于此"，禁止"含义：""做法："生硬模板。

## 二、观点现象分析题：表态替换释义

```
（抽象专有名词先解释）+表态（赞同/反对/辩证，材料原词，建议双词表态）
理由：合理性在于1.2.3.／不合理性在于1.2.（必须与表态呼应）
对策：因此，今后应……（好事推广；坏事据问题反推）
```

- 表态依据材料而非个人判断；陌生专有名词（带双引号）且材料有解释→先解释再表态（解释有分）。
- 表态常用词：赞同（正确、科学、合理、全面）；反对（不科学、不合理、片面、偏颇、绝对）；辩证（有利有弊、有待观察）。建议两个词表态（"片面的，因此是不科学的"），少用"正确/错误"。表态占分（如"片面的"1分+"不科学的"1分）。
- **表态与理由必须呼应**：态度"进步/值得点赞"→理由写"过去不好+现在好"。
- 评价"A→B变化"亚型：分别解释A、B定义→表态→理由（A的问题+B的意义）→对策（未来优化）。

## 三、评分规则

1. 逻辑分 2-3 分：释义/展开/总结三部分缺一不可——少 1 部分扣 1 分，少 2 部分不得逻辑分。
2. 要点分采点赋分（20 分题示例：释义 2 词=2 分，展开 3 条×4 分=12 分，总结 3 词=3 分）。
3. 定义解释错了失要点分但**不失逻辑分**（结构完整即保逻辑分）。
4. 综合题不强制分段；分段技巧：定义行尽量占满，第 2 段开头空 2 格，序号用①②（醒目且只占 1 格）。
5. 字数超格必扣卷面分；勾画时必得分点画圈、拿不准画波浪线，格子不够先舍波浪线（意义优先舍），做法不能舍。

## 四、批改检查清单

- [ ] 三段结构齐全？（缺释义/缺总结→扣逻辑分，这是综合题最常见硬伤）
- [ ] 释义是否就近出处？自编剧释/随手抄一句当释义=主观性失分。
- [ ] 展开要素与题干句表达方式匹配？（题干"要"字却全写意义=要素跑偏）
- [ ] 句内并列结构是否用作分类框架？
- [ ] 观点题：有无表态？表态与理由呼应？抽象名词先解释？对策结尾与材料态度一致？
- [ ] 有无与材料态度对着干（对新政策表否定=错；材料态度=考生态度）？
- [ ] 要点层面同单一题清单（原词、话题分条、等字/并列词后要点）。

## 五、典型失分模式

1. 缺结构：漏释义或漏总结，直接丢逻辑分。
2. 释义乱写：自编、随便抄一句，违反就近原则。
3. 要素跑偏：感情色彩判断错、题干句提示词（要/让/只有才）没跟上。
4. 表态与理由两张皮。
5. 首条过长挤占格子，后面要点没地方写。

## 六、范例锚点

- **2022 辽宁 B"穷帽子/老样子/好根子"**（20 分 300 字）：全材料无现成释义→从三部分要点挑最大词拼合（致富/环境/乡风）；展开严格按句内三排比分类；"要"字提示全篇侧重对策。
- **2021 江苏 B"累进式执法→现场直接处罚"评析**：双定义（就近原则）→表态（摘材料"举双手赞成"）→对比论证（A问题+B意义）→对策。先解释再表态最保险。
