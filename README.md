# shenlun-pigai · 申论批改 Skill

公务员考试**申论批改与诊断** AI 技能（WorkBuddy / Claude Code 类 Agent 通用 Skill 格式）。
基于粉笔李梦圆申论系统班（2027 国考 1 期）笔记体系构建，覆盖单一题、综合题、公文题、大作文四大题型的分维度批改、采点估分、失分诊断与阶段性提升路径。

## 能力概览

- **分维度批改**：审题偏差 / 逻辑结构 / 要点遗漏 / 语言规范 四维度逐项检查，每条意见对应知识库具体规则
- **采点估分**：按词赋分、总括词权重、逻辑分 / 格式分 / 语气分、作文"采词定档 + 档内浮动"，输出分数区间与得分率
- **失分诊断**：A 审题 / B 要点 / C 结构 / D 语言 四象限失分模式库，映射"根因 → 训练动作"
- **提升路径**：摸底定位 → 单一题筑基 → 综合+公文 → 作文 → 套卷冲刺 四阶段路线
- **持续进化**：进化日志版本追溯，支持吸收新资料 / 新真题 / 机构课程持续修正知识库

## 使用方法

1. 将整个文件夹放入 Agent 的技能目录（如 WorkBuddy：`~/.workbuddy/skills/`；Claude Code：`~/.claude/skills/`）。
2. 对话中提交申论作答（题干 + 你的答案，最好附材料），说"帮我批改"即可自动触发。
3. 投喂新资料时说"更新到申论批改技能"，知识库会按进化机制增量更新并记录版本。

## 核心批改哲学

1. **采点给分是灵魂**：按词赋分、多写不扣分、原词优先（"可以加词，不能改词"）
2. **结构分先行**：综合题三段逻辑分、公文格式/语气分、作文先定档再评档内浮动
3. **诊断可落地**：每个失分点映射到具体训练动作，而非空泛评价
